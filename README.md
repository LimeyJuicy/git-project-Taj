Git.java:

    initializeGit():
        This method initializes git, and does the following: 
        -Creates a git/ directory if it does not already exist
        -Creates an objects/ directory inside git/ if it does not already exist
        -Creates a file named index inside git/ if it does not already exist (no extension)
        -Creates a file named HEAD inside git/ if it does not already exist (no extension)
        -If all four already exist, prints: "Git Repository Already Exists"
        -Otherwise print: "Git Repository Created"
